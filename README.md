KMeans Clustering model applied to generated data blobs – 500 samples with 5 centers, fitted model, predictions, and clear visualization of clusters and centroids.

## Dataset
- Source: Generated using scikit-learn's `make_blobs` (500 samples, 5 centers, cluster std=0.70)
- Purpose: Simulate real-world clustered data for unsupervised learning

## Model
- Algorithm: KMeans (scikit-learn, n_clusters=5)
- Process: Fit on data, predict cluster labels
- Visualization: Scatter plot with viridis colormap for points, red markers for centroids

Output

.  Initial scatter plot of generated data
.  Clustered scatter plot with predicted labels and centroids marked
